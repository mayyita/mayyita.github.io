# Términos de servicio

**Última actualización:** 18 de noviembre de 2026

Al agregar Mayyita a un server o usar sus comandos aceptas estos términos y los [Términos de Discord](https://discord.com/terms).

**Contacto:** el [server de soporte de Mayyita](https://discord.gg/3keaaX6xPU), en el canal #ticket. No damos correo ni otros datos personales.

## Uso permitido

- Usa el bot dentro de las reglas de Discord.
- No intentes romperlo, saturarlo, buscar fallos para sacar ventaja (por ejemplo, duplicar monedas) ni usarlo para molestar o atacar a otros.
- No lo uses para nukear, hacer raids, spam o acoso. El anti-nuke y el anti-raid están para lo contrario.
- Si encuentras un fallo de seguridad, avísanos en privado antes de publicarlo.

## Economía y juegos

- Las monedas del bot (por ejemplo, "sangre") **no tienen valor real**. **No se venden por dinero real**, no se cambian por dinero y no se reembolsan.
- Los juegos son de entretenimiento, con monedas del bot. No son apuestas con dinero.
- Podemos corregir o revertir saldos ganados con trampas o fallos.

## Premium

- Premium y los beneficios por boostear el server de soporte son **cosméticos y de comodidad** (fondos, marcos y similares). **Nunca dan ventajas en la economía ni en los juegos.**
- Ver y borrar tus datos es gratis siempre, con o sin premium.

## Responsabilidad del server

- El staff de cada server decide cómo configura el bot y es responsable de las sanciones que aplica con él.
- El bot hace lo posible por proteger tu server, pero **ninguna protección es perfecta**. Configura bien los permisos de tu server.

## Disponibilidad

- El bot se ofrece **tal cual**, sin garantía de que funcione siempre ni sin errores. Puede tener caídas o cambios.
- No respondemos por daños o pérdidas por usar el bot o por no poder usarlo, dentro de lo que permite la ley.

## Suspensión

Podemos dejar de dar servicio a un usuario o a un server que rompa estos términos o las reglas de Discord.

## Cambios

Si cambiamos estos términos, actualizamos la fecha de arriba y lo avisamos en el server de soporte. Si sigues usando el bot después, aceptas los nuevos términos.

## Ley aplicable

Estos términos se rigen por las leyes del Perú.
